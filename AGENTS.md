# Proyecto: Animate

- App móvil en React Native con Expo (SDK 57, expo-router, TypeScript, código en `src/`).
- Backend/BBDD: Supabase. Cliente en `src/lib/supabase.ts`; credenciales en `.env` (ver `.env.example`).
- Compila para iOS y Android (y web). Arrancar con `npm start`, `npm run ios` o `npm run android`.
- La PRD del producto está (o estará) en la raíz del repo; el diseño de pantallas llegará vía Figma.
